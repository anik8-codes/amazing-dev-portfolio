# Scene sources (experience roadmap)

Processed by `pnpm scenes` (scripts/make-scenes.mjs) into `src/assets/scenes/`: cropped,
background removed, then turned into a duotone illustration (a 1-bit silhouette mask plus a
5-band greyscale shading mask), which the site paints in its own theme colours. The processed
versions are adaptations and are shared under the same licence as their source.
