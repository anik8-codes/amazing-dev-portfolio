# Security policy

Only the latest deploy of `main` is supported.

## Reporting a vulnerability

Please **don't open a public issue**. Report privately through GitHub's
[private vulnerability reporting](https://github.com/anik8-codes/amazing-dev-portfolio/security/advisories/new)
with the steps to reproduce and the impact.

You'll get a reply within 7 days. Once a fix is deployed you'll be credited in the advisory, unless you'd rather not be.

## In scope

The site, its API worker (`worker/`), and the infrastructure code in `infra/`.

## Out of scope

Third-party services the site uses (Cloudflare, Cal.com, Umami, Resend). Report those to their vendors.
